## 🚀 Key Projects

### 🎓 [EduTwin](https://github.com/edutwin-team) · [Live demo](https://edutwin.netlify.app/)

An AI-powered educational platform for creating digital learner twins, simulating different learner profiles, evaluating educational content and generating improvement recommendations. Built with REST APIs, persistent data and Agile teamwork.

### 📄 [ReussirSonCV](https://github.com/mohamedmaghzaoui/ReussirSonCV) · [Live demo](https://reussirsoncv.netlify.app/)

A web application for creating, customizing and exporting ATS-compatible resumes. It includes real-time preview, AI-powered resume analysis, responsive design, automated tests and a GitHub Actions CI/CD pipeline.

### 🤖 [AIGen](https://github.com/mohamedmaghzaoui/AIGen)

React/Vite and Django REST application that generates test data in JSON from custom schemas using Google Gemini. The project includes schema building, generation history and Docker Compose infrastructure.

### 💬 [Real-Time Chat App](https://github.com/mohamedmaghzaoui/chat-app)

Real-time messaging application built with React and Laravel, featuring secure authentication, private conversations, a RESTful API, SQLite migrations and Docker-based CI/CD.

### 🚗 [SmartFleetManager](https://github.com/mohamedmaghzaoui/SmartFleetManager)

React Native fleet management application with real-time GPS tracking, vehicle and maintenance monitoring, driving analytics, speed alerts and AI-assisted breakdown prediction.

### 🌦️ [Centralized Weather Station](https://github.com/mohamedmaghzaoui/stationMeteo)

Connected IoT monitoring solution using ESP32, MQ-135 and BME280 sensors. A Symfony REST API and React interface collect and display temperature, humidity, pressure and air-quality data in real time.

### 🗂️ [Back-Office](https://github.com/mohamedmaghzaoui/BackOffice)

Secure Symfony platform for managing projects, skills and associated images, with authentication, CRUD operations, search and custom sorting.
